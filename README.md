======Description Of Each Program======

1.Basic Data Types:
This program demonstrates the use of basic data types like int, char, and float to store student details.

2.If-Else:
This program checks whether a student has passed or failed based on the marks using an if-else statement.

3.Loop and Array:
This program stores five students' marks in an array and displays them using a for loop.

4.Functions:
This program demonstrates the use of a function to calculate the sum of two numbers.

5.Class and Object:
This program demonstrates how to create a class, create an object, store student details, and display them.

6.Constructor and Destructor:
This program demonstrates the automatic execution of a constructor when an object is created and a destructor when the object is destroyed.

7.Static Member:
This program demonstrates the use of a static member to count the number of objects created.

8.Inline and Friend Function:
This program demonstrates an inline function and a friend function to access and display private data of a class.
